# Halyard Display Medium webfont

Add the licensed, self-hosted webfont as `halyard-display-medium.woff2` in this folder. The CSS uses weight 500, normal style.

The font file is not included yet. Until it is supplied, browsers show the fallback typeface. Do not merge this draft as an exact font match until the real webfont has been added and visually checked.

No Adobe Fonts kit is required with this setup. The video, traced text paths, and external font-hosting dependencies have been removed from the homepage.

Browser checks cover CSS playback, pause/resume/replay, reduced-motion changes, 375px mobile sizing, disabled JavaScript, and missing-font fallback. Temporary foundry specimen data was used only in isolated tests and is not included or referenced by the site.
